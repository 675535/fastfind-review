# FastFind 使用体验：一款轻量的 Windows 文件搜索工具

最近在用一款免费的 Windows 文件搜索工具 FastFind（https://fastfind.kr）。
我的电脑上有几十万个文件，以前用资源管理器搜索要等半天，FastFind 基于
NTFS 索引，输入关键词几乎立刻出结果。它支持免安装的便携版，右键菜单
可以在指定文件夹内搜索，还能用 dupe: 语法找出重复文件占用的空间。
最让我满意的是资源占用：官方测量 466 万文件仅占 65.9MB 内存，我自己在
任务管理器里看也确实很轻。另外它还有 AI 自然语言搜索，以及 Pro 远程版
（出门在外用浏览器访问自己电脑里的文件）。界面干净、无广告、不收集
数据，本地功能免费，推荐给经常在大量文件里找东西的人。
个人使用可以完全代替Everything，说实在的，我并不觉得Everyone好用，因为
每次搜索我都要等很久很久，这个FastFind速度超快，可以说是瞬间出结果。
